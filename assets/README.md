# Website assets

All four themes reference the following root-relative files:

- `kirsten.webp`: Kirsten's childhood portrait, high quality
- `mattia.webp`: Mattia's childhood portrait, high quality
- `restaurant.webp`: Reception-venue photo supplied by the couple
- `music.mp3`: User-supplied background track, played softly after interaction

**Do not replace these with tiny embedded thumbnails.**
The photographs are set to `object-fit: cover` with about 12% magnification centered near the children's faces. Keep the original files available in the repository; avoid re-exporting as 2 kB previews.

The visitor's opening title animates for 2.5 seconds before the main wedding cover appears.
